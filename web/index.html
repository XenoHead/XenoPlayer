XenoPlayer Instructions

Media Controls

  • Space: Play / Pause
  • Left / Right Arrow: Previous / Next media
  • Loop: Enable to automatically repeat videos
  • Timer: Auto-advance images every X seconds

File Operations

  • Move Targets: Configure preset folders to quickly move files via the sidebar buttons
  • Delete Dupes: Scans current folder to remove duplicate media files
  • Favorites: Click the icon to favorite. View them via 'Play Favorites'
  • Create Image/Video CBZ: Bundle a folder's images or MP4/WebM/OGG clips into one playable .cbz archive

Reading

  • VIEW COLLECTION Button: Opens the current folder in the advanced Collection Viewer window
  • Online Media: Search, browse, and directly download collection into your library
